## 🚀 What I'm Working On

### 🛡️ Sentinel AI

**Email Phishing Detection & Threat Intelligence Platform**

A machine-learning powered cybersecurity platform designed to analyze suspicious emails and identify phishing threats.

**Core pipeline:**

```text
Email
  ↓
Preprocessing
  ↓
BERT Embeddings ──────┐
                      ├──→ Feature Fusion → XGBoost → Risk Score
Cybersecurity Features┘                         ↓
                                      Legitimate / Suspicious / Phishing
```

**Tech:** Python • BERT • PyTorch • Transformers • XGBoost • Scikit-learn • FastAPI • React • SQLite
